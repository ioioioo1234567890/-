                                                日本商业动画制作知识库RAG项目说明			
1. 项目简介

本项目聚焦日本商业动画垂直领域，搭建检索增强生成（RAG）知识库问答系统。通用大模型在动画专业场景存在明显短板，一是对动画专业术语、岗位职能、制作流程的解读精准度不足，二是无法严格匹配专属资料中的细节数据、流程规范与时间标准，易出现信息偏差。
本项目通过RAG架构，让模型优先检索专属动画知识库内容，再基于真实资料生成回答，有效规避通用模型的知识偏差与幻觉问题。项目核心重点为垂直领域数据清洗、结构化知识库搭建、RAG参数调优、专业问答评测、问题迭代优化，而非从零开发RAG底层框架。

2. 数据来源与知识库结构

2.1 数据来源

项目核心知识来源为日文专业书籍《アニメーションの基礎知識大百科 / Encyclopedia of Animation Basics》，原始资料为224页扫描型PDF，无法直接文本解析，需经过OCR识别与专业文档解析后投入使用。

2.2 知识库文件结构

经过清洗、拆分、结构化处理，最终投入使用的知识库共5份核心文档，剔除了项目预处理说明类无关文件，避免内容污染，具体分工如下：
- 00_日本商业动画完整制作流程总览.md：搭建整体制作流程结构化框架，作为全局问答入口，适配全流程类综合问题
- 01_日本商业动画制作流程.md：详细记录日本商业动画从企划到成片的全流程规范
- 02_日本商业动画制作岗位.md：梳理动画全链路制作岗位、核心职责与协作关系
- 03_动画制作进行与作画流程.md：聚焦制作进行工作体系、会议机制、作画流程与质量检查体系
- 04_日本商业动画制作专业术语.md：收录动画制作核心日文术语、释义与应用场景

3. 数据预处理流程

原始扫描PDF存在OCR识别噪声，包括日文识别错误、标题缺失、表格格式错乱、残留图片标签、数字符号异常、局部乱码等问题。为保证知识库专业性，制定标准化预处理流程：
扫描型PDF → OCR识别 → MinerU文档解析 → 初始Markdown文档 → 内容降噪清洗 → 专业信息校验 → 主题拆分归类 → 结构化知识库搭建
预处理重点校验动画专业术语、岗位名称、制作流程、会议规范、数字及时间细节，剔除所有项目说明、预处理记录等非专业知识内容，保障知识库内容纯净度。

4. RAG整体架构与参数配置

本项目基于FastGPT平台搭建RAG问答系统，采用「混合检索+重排优化+大模型生成」的完整链路，全程固定参数不随意改动，保障实验稳定性。

4.1 核心运行链路

用户提问 → 问题输入 → 知识库检索 → Hybrid Search混合检索（语义检索+全文检索） → Jina重排二次排序 → 筛选高相关知识片段 → GPT模型生成答案 → 输出答案+原文引用

4.2 关键参数配置

5. 核心方案选型依据

5.1 混合检索（Hybrid Search）选型原因

动画专业知识包含两类核心信息，单一检索方式无法适配全部场景：一是语义类问题，侧重流程逻辑、岗位作用、原理分析，依赖语义检索；二是固定专业术语、专有名词，依赖全文关键词精准匹配。
本项目通过「语义检索0.6+全文检索0.4」的权重配比，兼顾语义理解与术语精准匹配，再通过重排模型优化检索结果排序，最大化提升专业内容检索准确率。

5.2 FastGPT平台选型优势

项目核心目标为验证RAG在垂直专业领域的应用效果，而非研发底层架构。FastGPT可快速完成文档向量化、检索配置、重排调优、问答测试与效果迭代，可视化操作便捷，支持多组对比实验，适配课程项目的开发与评测需求。

6. 评测方案设计
为客观验证RAG优化效果，本项目自主构建30道专业测试数据集，摒弃主观观感评价，实现量化评测。测试问题覆盖动画制作全场景，分为6大题型，全面校验模型的知识准确性、完整性与细节适配性。

6.1 测试数据集分布

| 题型分类 | 题目数量 | 考察重点 |
| -------- | -------- | -------- |
| 基础术语 | 6 | 核心日文术语释义、基础定义 |
| 制作流程 | 5 | 全流程、分段流程的完整性与逻辑性 |
| 岗位职责 | 5 | 各岗位职能、协作关系 |
| 概念对比 | 5 | 相似专业概念的区分与差异 |
| 多跳推理 | 5 | 多流程、多岗位关联推理 |
| 细节数据 | 4 | 专属资料中的数字、时间等精准细节 |

6.2 评分标准

每道题目从正确性、完整性两个维度评分，单项满分2分，单题总分4分，满分共计120分。同时记录检索状态、是否存在幻觉、信息遗漏等问题，精准定位故障环节（数据/检索/生成）。
正确性：0分（核心事实错误）、1分（基本正确，存在瑕疵）、2分（核心事实完全准确）
完整性：0分（未作答核心问题）、1分（部分作答，存在遗漏）、2分（全面覆盖问题需求）
严格通过标准：单题正确性、完整性均为满分2分
7. 实验对比结果

本次实验采用单一变量原则，使用30道测试题分别对「普通大模型」与「RAG增强模型」进行对照测试，核心数据如下：

| 评测指标 | 普通大模型 | RAG增强模型 | 优化提升 |
| -------- | ---------- | ----------- | -------- |
| 正确性得分率 | 78.3% | 85.0% | +6.7% |
| 完整性得分率 | 66.7% | 80.0% | +13.3% |
| 严格通过率 | 46.7% | 70.0% | +23.3% |

实验结果表明，RAG架构通过专属知识库检索，大幅提升了动画专业问题回答的完整性与精准度，有效降低大模型幻觉问题，在垂直专业领域适配性远优于通用大模型。本结果仅适用于本次测试数据集，为项目效果验证使用，不作为通用行业基准。

8. 失败案例与问题迭代分析

实验过程中留存多类典型失败案例，精准定位RAG全链路问题，针对性优化迭代：

8.1 相似术语概念混淆

作打ち、キャラ打ち、演出打ち三类术语名称相似、场景相近，检索可命中正确内容，但模型生成时易出现概念污染，混淆相似定义。问题定位为生成阶段语义区分能力不足。

8.2 检索成功但作答偏离重点

针对動画チェック职责类问题，系统可检索到完整检查规范，但初始回答仅罗列整体检查体系，未聚焦核心问题，属于检索有效、生成聚焦性不足。

8.3 对比类问题信息整合不足

作画監督与動画チェック职责对比问题，检索可获取双方完整职能信息，但模型仅简单罗列内容，未提炼核心差异，信息整合与对比归纳能力欠缺。

8.4 复合问题细节遗漏

多维度复合提问（cut数量+作打时长）易出现细节数据遗漏，拆分单一问题可正常作答，属于复合问题信息提取能力不足。优化方案为通过提示词约束，要求模型逐项拆解问题、优先输出知识库精准数字与时间细节。

8.5 原始数据噪声影响

扫描PDF的OCR识别误差，导致部分小标题缺失、格式错乱，影响检索匹配效果。通过新增全局总览文档，搭建结构化知识框架，弥补原始数据缺陷。

10. 项目时间投入与规划

10.1 个人实际投入

剔除纯模型生成耗时，本人累计专项投入2天，核心用于数据清洗校验、知识库结构化搭建、参数调优、评测实验、问题复盘与报告整理，其中数据处理、效果调试、结果分析为核心耗时环节。

10.2 标准化项目规划

1. 需求与数据准备（0.5-1天）：确定垂直领域、核验原始资料格式、制定OCR预处理方案
2. 数据预处理（1天）：OCR识别、文档解析、内容清洗、主题拆分、专业信息校验
3. RAG系统搭建（0.5-1天）：创建知识库、配置检索与重排参数、对接大模型、基础问答调试
4. 评测体系搭建（0.5天）：设计多维度测试集、制定量化评分标准
5. 测试与迭代优化（1-2天）：完成普通模型与RAG模型对照实验、分析失败案例、针对性调优
6. 最终交付（0.5天）：整理实验数据、撰写项目报告、发布公网可访问知识库

11. 项目总结

本项目完整完成了日本商业动画垂直领域RAG知识库的搭建、评测与迭代工作。通过30道专业测试题对照实验，验证了RAG架构可有效弥补通用大模型在垂直专业领域的短板，显著提升回答的准确率与完整性。
项目实践总结出核心结论：RAG最终效果由数据质量、知识库结构、向量检索、重排优化、提示词设计、评测迭代全链路共同决定，单一环节缺陷均会导致问答效果偏差。同时，实验也证明检索成功不代表回答精准，模型生成阶段的语义区分、信息整合、细节提取能力同样是影响问答质量的关键因素。
